## Ranking work after launch

Metadata can make Scout relevant for the right searches; it cannot manufacture the number-one position. The durable levers are a low uninstall rate, successful first-run completion, repeat usage, honest reviews from real users, fast support, and a consistently policy-compliant publisher record. Track impressions → listing visits → installs → retained users by release, and change one major listing element at a time so conversion changes are interpretable.
